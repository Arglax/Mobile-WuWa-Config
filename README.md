# wwdec — Wuthering Waves Log Decryptor

A lightweight browser-based tool that decrypts encrypted `Client.log` files from recent Wuthering Waves builds (v3.4+).

**No install. No uploads. Runs entirely in your browser.**

---

## Usage

1. Open the tool: [Log Decryptor](https://arglax.github.io/Mobile-WuWa-Config/)
2. Click **Choose File** and select your `Client.log`
3. Click **Decrypt**
4. `client_decrypted.txt` downloads automatically

Your log file never leaves your device.

---

>[!Important]
>Your encrypted Client.Log should start with "TP" for this method to work. I might not update this tool.
